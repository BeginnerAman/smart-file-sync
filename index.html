FEATURE MATRIX

Engineered for Performance, Safety & Control

Enterprise-grade synchronization architecture built for speed, automation, and strict data integrity.

Win32 Kernel DMA FastCopy

Invokes Windows native CopyFileExW with DMA hardware acceleration, bypassing userspace buffer allocation for maximum I/O throughput.

Sliding Window (1 to 32 Threads)

Bounded concurrency window keeps memory under 5 MB regardless of queue size, enabling instantaneous millisecond Pause and Stop response.

Block-Level Delta Transfer

4KB block signature comparison on files ≥ 1MB transfers only modified chunks. Saves up to 99.8% bandwidth on databases and videos.

FAT32 2s Tolerance & USB Auto-Detect

Automatic 2.0s timestamp buffer prevents false 'Modified' alerts on FAT32/exFAT drives, while hardware threads detect USB plug-ins instantly.

Automated Periodic Scheduler

Built-in background timer executes unattended synchronizations at configurable intervals (every 5 min, 15 min, 30 min, 1 hr, or 2 hr).

Pre & Post Sync Automation Scripts

Hook custom batch scripts, PowerShell commands, or Python scripts to run before sync begins or after completion (e.g. database pause or auto-eject).

Multi-Version File Archiving

Configurable safety archive keeps 1, 3, or 5 historical versions of modified files in structured backup trees before replacement.

Bandwidth Rate Limiting

Adjustable throughput limiter (0 to 100 MB/s or unlimited) prevents background synchronization from consuming critical disk or LAN bandwidth.

Zero-Lag Virtualized Tables

40ms batched flusher and O(1) header calculations ensure silky smooth 60 FPS scrolling and instant search even on 66,000+ files.

Atomic Writes & Loop Protection

Files stream to .smartsync.tmp staging files before atomic swap. Path validation prevents recursive loops when target is inside source.

Persistent Metadata Scan Caching

Maintains persistent JSON filesystem index caches so subsequent differential scans of 100,000+ files finish in fractions of a second.

Enterprise UNC & Headless CLI

Full support for Windows extended paths (\\?\UNC\...) exceeding 260 characters and full CLI execution via Task Scheduler.

64-Bit Multi-Terabyte Scale

Engineered with native 64-bit integer metadata streaming (qint64), guaranteeing zero 32-bit overflow errors on massive multi-terabyte drives.

Smart Destination Auto-Creation

Distinguishes between unmounted USB drives and brand-new target folders. Target backup folders are marked as 0 B (New) and auto-created on scan.

Hardware 1:1 Adaptive Presets

Presets scale dynamically to CPU cores (Balanced matches 1:1 with hardware cores, e.g. 8 cores = 8 threads), with right-click Explorer integration in Queue.

COMMAND LINE INTERFACE

Automate with Headless CLI Execution

Run silent synchronization tasks in Windows Task Scheduler, PowerShell, or command scripts.

PowerShell · CLI Sync Command 
PS C:\> python -m smart_sync --src "D:\Photos" --dst "E:\Backup" --mode mirror --threads 8 --verify
--src <path>

Source folder directory to scan and copy from.

--dst <path>

Destination directory path to sync into.

--mode {copy,mirror,two-way}

Copy, mirror (deletes destination extras), or two-way bidirectional sync.

--threads <N>

Configure parallel worker thread count (1 to 32, default: 4).
